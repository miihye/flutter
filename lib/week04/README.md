## 📋 제출 항목 및 구현 내용

### 1. 모바일 화면 개요
- **보여 주기·배치·동작 위젯**을 조합하여 구현한 1페이지 프로필 및 정보 카드 화면입니다.
- 주요 기능: 머리말 프로필 표시(AC1), 스크롤 가능한 정보 카드 리스트(AC2), 피드백 버튼 및 SnackBar 동작(AC3).

### 2. 위젯 선택표
* **만들 기능**: 전체 앱 기본 화면 틀 구성
  * **위젯 범주**: 보여 주기
  * **선택한 위젯**: `Scaffold`, `AppBar`
  * **선택 이유**: 앱의 기본 뼈대 구조를 잡고 상단에 제목 바를 표시하기 위함

* **만들 기능**: 머리말 프로필 표시 (AC1)
  * **위젯 범주**: 보여 주기 / 배치
  * **선택한 위젯**: `CircleAvatar`, `Text`, `Row`
  * **선택 이유**: 원형 아바타 아이콘과 본인 이름·전공 텍스트를 가로 방향으로 나란히 배치하여 머리말을 구성하기 위함

* **만들 기능**: 정보 카드 리스트 표시 (AC2)
  * **위젯 범주**: 배치 (Scrollable)
  * **선택한 위젯**: `ListView`, `Card`, `ListTile`
  * **선택 이유**: 여러 개의 정보 카드 항목을 세로로 나열하고, 화면 스크롤이 가능하도록 구성하기 위함

* **만들 기능**: 버튼 클릭 상호작용 (AC3)
  * **위젯 범주**: 동작 / 사용자 반응
  * **선택한 위젯**: `ElevatedButton`, `SnackBar`
  * **선택 이유**: 사용자가 버튼을 터치했을 때 하단에서 결과 피드백 메시지가 나타나도록 동작을 구현하기 위함

### 3. 결정 근거표
* **공식 문서 위치**: `flutter.dev/docs` > `CircleAvatar`
  * **확인 내용**: 원형 배경을 만들고 그 안에 아이콘이나 텍스트, 이미지를 쉽게 중앙 정렬할 수 있는 위젯
  * **현재 화면에 적용한 이유**: AC1 조건인 머리말 영역의 프로필 아바타를 직관적이고 깔끔한 원형 형태로 표현하기 위해 적용

* **공식 문서 위치**: `flutter.dev/docs` > `ListView`
  * **확인 내용**: 여러 자식 위젯들을 세로 또는 가로로 스크롤 가능한 목록 형태로 렌더링하는 위젯
  * **현재 화면에 적용한 이유**: AC2 조건인 3개의 정보 카드를 화면 크기를 초과하더라도 사용자가 스크롤하여 모두 확인할 수 있도록 하기 위해 적용

* **공식 문서 위치**: `flutter.dev/docs` > `ScaffoldMessenger`
  * **확인 내용**: `Scaffold` 하위에 `SnackBar`를 띄워 임시 메시지나 피드백을 사용자에게 시각적으로 전달하는 메커니즘
  * **현재 화면에 적용한 이유**: AC3 조건인 버튼 클릭 이벤트 발생 시 화면 하단에 실행 결과 메시지를 띄우는 상호작용을 구현하기 위해 적용
