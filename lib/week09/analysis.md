# 🔍 9주차 주제 분석 및 후보 비교 (Analysis)

## 1. 후보 비교 및 판단
* **후보 A:** 감정 기반 3D 공유 일기 앱 (7주차 초기 아이디어)
* **후보 B:** 결정장애 식사 룰렛 앱 (현재 채택안)
* **비교 판단:** 
  * 후보 A는 3D 렌더링 및 Supabase 백엔드 연동이 필요하여 10주차부터 바로 구현을 시작하기에 기술적 난이도와 위험 부담이 높음.
  * 후보 B는 상태 관리(`setState`)와 비동기(`Future`)라는 핵심 기술에 집중할 수 있으며, 단기간 내에 명확한 성공/실패 시나리오(AC)를 증명할 수 있어 과제 목적에 더 부합함.

## 2. 유사 앱 조사 및 차별점
* **유사 앱:** 
  1. **일반 룰렛 앱 (결정 룰렛 등):** 사용자가 직접 룰렛 항목을 다 입력해야 해서 귀찮음.
  2. **배달 앱 (배민 등):** 옵션이 너무 많고 시각적 자극이 많아 오히려 고르기가 더 힘듦.
* **본인 앱의 차별점:** 항목을 입력할 필요 없이 오직 "시간대(점심/저녁)"와 "수단(배달/집밥)" 딱 두 가지만 묻고 앱이 알아서 최종 결과 1개를 강제로 지정해 주어 뇌의 피로를 극단적으로 줄여줌.

## 3. 중간 확인 및 범위 조정 기록
* 7주차 기획 당시 외부 레시피 영상 재생이나 배달 앱 연동을 고려했으나, 교재 진도(Flutter UI 기초 및 비동기 상태 제어)에 맞추기 위해 **외부 의존성을 완전히 제거(Drop)**하는 것으로 범위를 과감히 축소함.
* 이를 통해 남은 기간 동안 UI의 완성도와 앱의 안정성(중복 클릭 방지, 에러 복구)을 높이는 데 집중하기로 결정.
