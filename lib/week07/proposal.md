# 📱 개인 앱 아이디어 기획서 및 MVP 인수 조건 (Proposal)

* **학생 정보:** 컴퓨터소프트웨어학과 / 2025136004 / 장미혜
* **앱 이름:** 뭐 먹지? (결정장애를 위한 식사 룰렛)

## 1. 문제 및 사용자
* **대상 사용자:** 매일 점심, 저녁 메뉴를 고르는 데 스트레스를 받는 대학생 및 직장인 (결정장애 보유자)
* **해결하려는 문제:** 식사 시간마다 '배달을 시킬지, 집밥을 해 먹을지', '어떤 메뉴를 먹을지' 고민하느라 버려지는 시간과 감정 소모를 줄여줌.

## 2. 가치 및 MVP 범위
* **제공 가치:** 사용자의 최소한의 선택(점심/저녁, 배달/집밥)만으로 즉각적이고 명확한 식사 메뉴 하나를 추천하여 결정 스트레스를 해소함.
* **MVP 포함 기능:** 식사 시간(점심/저녁) 선택, 식사 방식(배달/집밥) 선택, 랜덤 메뉴 1개 추천 기능.
* **보류/제외 기능:** 배달 앱(배달의민족 등) 직접 연동 결제, 복잡한 요리 레시피 단계별 안내 기능 (MVP의 핵심인 '결정' 자체에 집중하기 위해 제외).

## 3. 제약, 화면 및 데이터
* **저장 방식 및 환경:** Flutter 모바일 앱 환경. 메뉴 데이터는 앱 내장(Local) 리스트로 관리하며, 향후 로컬 DB(SharedPreferences)에 최근 추천 기록 저장.
* **개인정보 범위:** 별도의 회원가입 없이 기기에 로컬로 저장되므로, 수집되는 민감한 개인정보는 없음.

## 4. 앱 인수 조건 (AC) (행동·기대 결과·확인 방법)
* **AC1 (정상 흐름):** 
  * 행동: 사용자가 '저녁'과 '배달'을 선택하고 '추천받기' 버튼을 누름.
  * 기대 결과: 치킨, 족발 등 배달 메뉴 중 1개가 화면에 무작위로 표시됨.
  * 확인 방법: 결과 화면 중앙에 추천 메뉴 텍스트와 아이콘이 올바르게 뜨는지 확인.
* **AC2 (빈 상태 / 예외 처리):** 
  * 행동: 옵션(점심/저녁, 배달/집밥)을 하나도 선택하지 않고 '추천받기' 버튼을 누름.
  * 기대 결과: "식사 옵션을 먼저 선택해주세요"라는 경고 메시지(스낵바)가 나타나며 다음 화면으로 넘어가지 않음.
  * 확인 방법: 필수 값 누락 시 스낵바 노출 및 화면 전환 차단 여부 확인.
* **AC3 (상태 초기화):** 
  * 행동: 추천 결과를 확인한 뒤 '다시 고르기' 버튼을 누름.
  * 기대 결과: 선택했던 모든 옵션이 빈 상태로 초기화된 메인 화면으로 돌아옴.
  * 확인 방법: 메인 화면의 버튼 선택 상태가 모두 해제되어 있는지 확인.
* **AC4 (실패 및 재시도 로직):** 
  * 행동: 외부 데이터나 비동기 로딩 중 오류가 발생함.
  * 기대 결과: 로딩 화면 대신 "메뉴를 불러오는 데 실패했습니다." 문구와 '재시도' 버튼이 표시됨.
  * 확인 방법: 에러 화면 노출 및 '재시도' 버튼 클릭 시 다시 비동기 호출(Future)이 실행되는지 확인.
