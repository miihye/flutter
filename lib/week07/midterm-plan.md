# 📊 1~7주차 학습 점검 및 보완 계획 (Midterm Plan)

## 1. 학습 점검
* **1~5주차:** `StatelessWidget`과 `StatefulWidget`의 차이를 이해하고, 상태 변경(`setState`)에 따른 UI 갱신 흐름 학습 완료. 
* **6주차:** `Future`와 `async`/`await`를 활용해 가상의 로딩(지연) 상태를 만들고, 성공/실패 시나리오에 따른 예외 처리 적용 완료.

## 2. 보완 계획 (앱 적용)
* 사용자가 '추천받기'를 눌렀을 때 즉시 결과가 나오는 것보다, 1~2초간 `Future.delayed`를 주어 룰렛이 돌아가는 듯한 '로딩 중' 화면을 보여주도록 6주차 비동기 개념을 앱에 결합할 예정.
* 상태 관리 코드가 길어지는 것을 방지하기 위해, 데이터(메뉴 리스트)와 UI 코드를 별도 파일로 분리하는 연습 진행 필요.
