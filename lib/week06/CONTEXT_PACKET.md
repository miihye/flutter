## 2. AC1–AC5 검증 기록 및 관측 결과
| 인수 조건 (AC) | 검증 내용 | 실제 관측 결과 | 판정 |
| :--- | :--- | :--- | :--- |
| **AC1** | 초기 상태에서 로딩·성공·실패 구분이 가능한지 확인 | 앱 실행 직후 '대기 중' 상태 및 안내 문구 정상 표시 | **통과 (Pass)** |
| **AC2** | 공지 요청 시 '로딩 중' 화면이 정상 노출되는지 확인 | 버튼 클릭 시 '로딩 중...'으로 즉시 변경 및 추가 클릭 차단 | **통과 (Pass)** |
| **AC3** | 성공 응답 시 공지 내용이 화면에 갱신되는지 확인 | 2초 후 '성공' 상태로 변경 및 최신 공지 텍스트 출력 | **통과 (Pass)** |
| **AC4** | 실패 응답 시 오류 메시지 표시 및 복구(재시도) 가능한지 확인 | 실패 시나리오 실행 시 오류 메시지 출력 및 재시도 가능 | **통과 (Pass)** |
| **AC5** | 중복 클릭 전후 요청 횟수가 제어되는지 확인 | 로딩 중 연타 시 요청 횟수가 증가하지 않고 1회만 수행됨 | **통과 (Pass)** |

## 4. 학습 기록 및 핵심 개념 요약
* **Future와 Stream:** 단일 비동기 요청에는 `Future`, 연속적인 데이터 스트림에는 `Stream`을 사용함.
* **동시성과 병렬성:** `async`만으로는 CPU 연산이 다른 스레드로 이동하지 않으며, I/O 대기 처리를 효율화하는 동시성 모델임.
